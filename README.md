# @lase-launcher/layout-utils


Util classes used to create the layout for Lase-Launcher application. 

> See documentation on https://launcher.asdep.fr/documentation/developpers

## Installation

```bash
# With npm
npm install @lase-launcher/layout-utils

# With pnpm
pnpm add @lase-launcher/layout-utils
```
